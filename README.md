# Bouncy Brawl 3000

Hello! This is **Bouncy Brawl 3000**! A 2D Platform fighting game with Bouncy Knockback Mechanics.
Play as a sword-wielding knight, master melee combat, and take on three unique bosses: the fireball-slinging Mage, shield-wielding Captain Canada, and the GOAT Shoebum.
# Tools
- Godot: Game Engine
- Antigravity: AI code help

## Features

 - Health System(out of 125)
 - Stamina System(preventing spam)a
 - Bounce Percent(Modiefer to add knockback)
 - Melee Combat
 - Regenerative Health System(+15 HP every 20 seconds)
 - Bounce Platforms(Gives second try)
 - Floating Arena
  
# Bosses
 - Mage
	 - Throws Fireball
 - Captain Canada
	 - Throws his Maple Leaf Shield
 - Shoebum
	 - Slaps you and stomps on the ground
